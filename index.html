渋滞データの接続

事故と渋滞の情報は TomTom から取得します。無料キーを一度入れるだけで、以後はこのスマホで自動的に使われます。

  1. my.tomtom.com で無料登録・ログインする
  2. ログインしたまま キーの一覧ページ を開き、表示される英数字のキーをコピーする
  3. 下の欄に貼り付けて「接続」を押す

キーはこのブラウザの中にだけ保存され、外部には公開されません。

ルート探索（Google）

日本の道路で正確なルートと到着時間を出すために Google のキーを使います。個人で使う分は毎月の無料枠に収まります（登録にクレジットカードが必要です）。

  1. Google Cloud に Google アカウントでログインし、プロジェクトを作る（名前は「渋滞マップ」など）
  2. 案内に従って「お支払い（請求先アカウント）」を登録する
  3. Routes API のページを開き「有効にする」を押す
  4. 認証情報のページで「認証情報を作成」→「APIキー」を押し、表示されたキー（AIza で始まる）をコピー
  5. 安全のため、そのキーの編集画面で「ウェブサイト」に https://akibakazuyuki.github.io/* を追加し、「APIの制限」で Routes API だけを選んで保存
  6. コピーしたキーを下に貼り付けて「保存」

施設の検索（任意・無料）

ゴルフ場やお店など、目的地の施設を探しやすくなります。Yahoo! JAPAN の「Client ID」を使います。

  1. Yahoo! JAPAN ID でログインして アプリケーションの登録 を開く
  2. 「クライアントサイド（Yahoo! ID連携 v2）」を選び、アプリ名に「渋滞マップ」、サイトURLに https://akibakazuyuki.github.io/ を入れて登録する
  3. 表示された「Client ID」をコピーして、下に貼り付ける
